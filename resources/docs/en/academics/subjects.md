Open **Academics** > **Classes** > **Subjects**.

## Add a subject

1. Type the **Subject name** (for example `Mathematics`).
2. Optionally type a short **Code** (for example `MATH`).
3. Choose **Save**.

Subject names must be different within the school, and so must codes. Leave the code empty if you do not use codes.

## Change or delete

Use **Edit** to change a subject's name or code and **Delete** to remove it. Later parts of Somaplus that use subjects (such as marks) will keep a subject from being deleted while it is still in use.
