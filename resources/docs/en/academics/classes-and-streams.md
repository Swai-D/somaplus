Open **Academics** > **Classes** > **Class list**.

## Add a class

1. Type the **Class name** (for example `Form 1` or `Standard 4`).
2. Give it an **Order** number. Classes are listed from the smallest number to the largest.
3. Choose **Save**.

Class names must be different within the school.

## Add streams

A stream is a parallel group of one class, for example `A` and `B` in Form 1. A class without streams is one group.

1. Open the class from the list.
2. Fill in **Add a stream** and choose **Save**.

Stream names must be different within the class, but two classes can each have a stream `A`.

## Delete

A class that still has streams cannot be deleted. Delete its streams first.
