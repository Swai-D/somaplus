Open **Academics** > **Exams** > **Grading scales**. Owners and head teachers can add and change scales; teachers can look.

## How a scale works

Each line is the **lowest percentage** that earns a grade. A mark is turned into a percentage of the exam's maximum, and the grade is the line with the highest "From" that the percentage reaches. For example:

| From (%) | Grade |
|---|---|
| 80 | A |
| 70 | B |
| 60 | C |
| 50 | D |
| 0 | F |

79.99 percent is a B and exactly 80 is an A. One line must start at **0**, so that every mark gets a grade. Because every line only says where a grade starts, there can never be a gap or an overlap.

## Add a scale

1. Choose **Add a grading scale** and type a name.
2. Fill in the lines: **From (%)**, **Grade**, and optionally **Points** and a **Remark**. Empty lines are ignored.
3. Choose **Save**.

Decimals such as 44.5 are allowed. Grades and "From" values must be different on every line.

## A scale in use cannot change

Once an exam uses a scale, the scale cannot be changed or deleted, so the grades of a past term never change. To use different grades, choose **Copy**, change the copy, and give it to new exams. See [Exams and locking](help:exams/exams-and-locking).
