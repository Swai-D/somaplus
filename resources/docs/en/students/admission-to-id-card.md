Follow these steps for each new student, or for a whole intake.

1. **Register.** Add the student (**Add student**), or many at once with **Import students** ([from a file](help:students/bulk-import)). Choose the class and add a parent or guardian.
2. **Admission number.** Somaplus gives it when you save if the owner chose automatic numbers; otherwise you type it ([Admission numbers](help:students/admission-numbers)).
3. **Invoice.** Under **Finance** > **Invoices**, make the invoices of the class from its fee structure, so the new student has one ([Invoices](help:fees/invoices)).
4. **Payment.** Record the payment against the invoice, or let it arrive from the bank, GePG or mobile money, and print the receipt ([Payments and receipts](help:fees/payments-and-receipts)).
5. **ID card.** Print the card for the student or the class ([ID cards](help:students/id-cards)).

If a parent has several children, the parent is saved once, by phone number, and linked to each child.
